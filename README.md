## Project Description
ModernTech HR System is a front-end proof of concept web application created for ModernTech Solutions. The system demonstrates how HR staff can manage employee information, payroll, digital payslips, leave requests, attendance tracking and reports using a centralised digital platform.


## Technologies Used
- HTML
- CSS
- JavaScript
- Vue.js
- Bootstrap

## Key Features
- login system with credentials
- Responsive dashboard for HR staff
- Employee management with 15 dummy employee records
- Add, view, edit and delete employees
- Employee search and department filtering
- Payroll calculations using predefined deduction rules
- Digital payslip generation with print option
- Leave request submission, approval and rejection
- Attendance tracking linked to approved leave
- Data visualisation reports using charts
- Client-side form validation
- Responsive design for desktop, tablet and mobile screens
